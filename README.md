## Ответы на вопросы:
1. Чем Console.Write() отличается от Console.WriteLine()?
   Console.Write() выводит текст в консоль и оставляет курсор на той же строке. Console.WriteLine() выводит текст и автоматически переводит курсор на новую строку (добавляет символ перевода строки)
2. Что произойдёт, если попытаться присвоить переменной типа int значение 3.14?
   Произойдёт ошибка компиляции. Компилятор C# не позволяет неявно преобразовывать тип с плавающей точкой (double) в целочисленный (int), так как это приведёт к потере данных. Для этого нужно использовать явное приведение: int x = (int)3.14; (результат будет 3)
3. Почему 10 / 3 в C# даёт 3, а не 3.333...? Как получить дробный результат?
   Потому что оба операнда являются целыми числами (int). При делении целых чисел в C# отбрасывается дробная часть. Чтобы получить дробный результат, нужно привести хотя бы один операнд к double: 10.0 / 3 или (double)10 / 3.
4. Что означает var в C#? Чем он отличается от динамической типизации в Python?
   var—это неявная типизация. Компилятор сам определяет тип переменной на основе присваиваемого значения, но тип фиксируется навсегда. В Python типизация динамическая: тип переменной может меняться во время выполнения программы (например, в переменной можно сначала хранить число, а потом строку). В C# с var так сделать нельзя
